# 2026.274.2208 — docs: the teardown verb is charly deploy del, not charly fleet del

## Summary

The command that tears a `local:` deploy back down is `charly deploy del`. This repo still named it `charly fleet del` in three places, left over from the fleet → deploy command rename:

- the candy `description:` (`candy/plugin-deploy-local/charly.yml`), which is also the published reference prose for this plugin on opencharly.ai;
- the package doc comment (`candy/plugin-deploy-local/plugin.go`);
- the `README.md`.

All three now say `charly deploy del`. The teardown word is registered as `command:deploy` by plugin-fleet (`plugin-fleet/candy/plugin-fleet/charly.yml`); no `fleet` command word exists.

Part of opencharly/charly#747 (README and docs truth audit).
